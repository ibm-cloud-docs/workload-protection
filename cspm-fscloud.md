# {{site.data.keyword.cloud_notm}} Framework for Financial Services
{: #financial-services}

In this change log, you can learn about the latest changes, improvements, and updates for the {{site.data.keyword.cloud_notm}} Framework for Financial Services policy. The change log lists changes that were made, ordered by the version number.

When controls are edited, removed from, or added to this policy in a way that is not compatible with the current version, a new minor version is released. To take advantage of the changes in a new version, [link the new policy to your zone](https://docs.sysdig.com/en/sysdig-secure/manage_posture_policies/#link-the-policy-to-a-zone){: external}.

## Version 2.0 v2.0
{: #version-2-v2}

The following changes were made to the {{site.data.keyword.cloud_notm}} Framework for Financial Services 2.0 v2.0 policy compared to the {{site.data.keyword.cloud_notm}} Framework for Financial Services 2.0 policy.

The {{site.data.keyword.cloud_notm}} Framework for Financial Services 2.0 v2.0 policy contains 418 unique posture controls, an increase of 170 controls compared to the 248 unique controls in the {{site.data.keyword.cloud_notm}} Framework for Financial Services 2.0 policy.
{: note}

The {{site.data.keyword.cloud_notm}} Framework for Financial Services 2.0 v2.0 policy includes 24 Kubernetes and Docker posture controls that evaluate your workloads. If you use {{site.data.keyword.containershort_notm}} or {{site.data.keyword.redhat_openshift_notm}} clusters, you must install the {{site.data.keyword.sysdigsecure_short}} agent in your clusters to evaluate these controls. For more information, see [Deploying the agent on Kubernetes clusters](/docs/workload-protection?topic=workload-protection-agent-deploy-kube-helm) and [Deploying the agent on {{site.data.keyword.redhat_openshift_notm}} clusters](/docs/workload-protection?topic=workload-protection-agent-deploy-openshift-helm).
{: important}
